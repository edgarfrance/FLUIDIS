# Amblia Web — Refonte Web et Accessibilité pour PME et Commerces

Landing page à fort taux de conversion dédiée à la refonte de sites web et landing pages pour commerces, restaurants et PME (accessibilité numérique WCAG 2.2 AA / RGAA, Directive Européenne 2025, design sobre et épuré).

- **Nom commercial :** Amblia Web (Amblia)
- **Éditeur :** Entreprise Individuelle (EI) EDGAR DUPRAT
- **Nom de domaine :** `ambliaweb.com`
- **Hébergement :** Vercel Inc.

## 🚀 Déploiement Vercel via GitHub

Ce projet est 100% prêt pour Vercel :
1. ✅ **`package.json`** : dépendances nettoyées et compatibles Vite 8.
2. ✅ **`.npmrc`** : `legacy-peer-deps=true` configuré pour un build fiable.
3. ✅ **`vercel.json`** : configuration du build et réécriture SPA.
4. ✅ **Pages légales intégrées :** Mentions Légales, Politique de Confidentialité (RGPD) et Déclaration d'Accessibilité (WCAG 2.2 AA).

### Pour synchroniser les derniers changements :

```bash
git add .
git commit -m "feat: branding Amblia Web, domaine ambliaweb.com et modales légales complètes"
git push origin main
```

---

### Commandes utiles en local

- `npm install` : installer les dépendances
- `npm run dev` : lancer le serveur local sur `localhost:3000`
- `npm run build` : générer le bundle de production dans `/dist`
- `npm run lint` : vérifier les types TypeScript
